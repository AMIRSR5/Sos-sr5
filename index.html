اگه پیام‌رسان باز نمی‌شه (فیلتر یا مشکل اینترنت)، از این دو دکمه که بدون اینترنت هم کار می‌کنن استفاده کن:

📞 تماس با پدر ✉️ پیامک آماده

این ابزار مستقل است و توسط تلگرام یا هیچ شرکت دیگری پشتیبانی نمی‌شود. قبل از نیاز واقعی، حتماً با دکمه «تست ارسال» در تنظیمات، اتصال را بررسی کنید.

تنظیمات ربات پیام‌رسان

این اطلاعات فقط داخل همین گوشی و همین مرورگر ذخیره می‌شود و به جایی ارسال نمی‌شود، مگر لحظه‌ای که خودتان دکمه کمک را بزنید.

این شماره فقط برای دو دکمهٔ «تماس» و «پیامک» استفاده می‌شه که با آنتن معمولی کار می‌کنن، حتی اگه تلگرام فیلتر باشه یا VPN نداشته باشی.

راهنما: چطور توکن و چت آیدی رو بگیرم؟

برای بله (پیشنهادی):

  1. داخل اپ بله، دنبال botfather@ بگردید، پیام بدید و /newbot بزنید تا یک توکن بگیرید.
  2. یک پیام (مثلاً «سلام») از حساب خودتان یا پدرتان به ربات جدید بفرستید.
  3. در مرورگر آدرس زیر را باز کنید (به‌جای TOKEN، توکن را بگذارید):
    https://tapi.bale.ai/botTOKEN/getUpdates
  4. دنبال "chat":{"id":... بگردید؛ همون عدد Chat ID شماست.

برای تلگرام:

  1. در تلگرام دنبال @BotFather بگردید و /newbot بزنید تا توکن بدهد.
  2. یک چت با ربات جدیدتون باز کنید و یک پیام بفرستید.
  3. آدرس زیر را باز کنید:
    https://api.telegram.org/botTOKEN/getUpdates
  4. دنبال "chat":{"id":... بگردید.

در هر دو حالت، اگر می‌خواهید مستقیم برای پدرتون بره، بهتره یک گروه دو/سه‌نفره با پدرتون و ربات بسازید و Chat ID همان گروه (که با علامت منفی شروع می‌شود) را استفاده کنید — یا Chat ID خودِ پدر را بگیرید (باید اول او به ربات پیام بدهد).
